Glulam beam sizing

Preliminary uniform-load beam check. Gives a starting section — not a substitute for a stamped calculation.

Assumes uniform load. Enter more than one span (comma-separated, e.g. "6,6" for a beam on 3 evenly-spaced posts) and each bay is checked as its own simple span, with the worst bay sizing the whole beam — that's conservative versus a true continuous-beam analysis (a real continuous beam usually sees lower moment over an interior support), not unconservative, but it will occasionally call for more beam than a continuous-beam calc strictly requires. Width is fixed by your selection above — the calculator solves only for the required depth at that width; it will not swap you to a different width to save material. Default is 5-1/2", Tamarack's typical beam width. Note two separate glulam width families exist: 5-1/2"/7-1/2"/9-1/2" are the Southern Pine series, manufactured net-width to match dimension lumber (flush with a 2x6/2x8/2x10 wall or post); 3-1/8"/5-1/8"/6-3/4"/8-3/4" are the Western species (Douglas Fir) series, which do NOT match dimension lumber widths. Confirm which series your supplier stocks before specifying. Verify bearing, lateral-torsional buckling (CL), and connection design separately.

Sawn lumber joist spans

Douglas Fir-Larch, calculated from the load and deflection limit you enter below — not a fixed table.

Calculated from standard NDS-style Fb/E design values for DF-L (with size factor CF and a 1.15 repetitive-member factor, since these tables assume joists spaced ≤24" o.c.), checking bending and live-load deflection only — shear and bearing at supports are not checked here, same as the Glulam tab. These will not exactly match a specific published AWC/IRC span table (which may use slightly different reference values), so still confirm against the current adopted IRC/AWC span tables and Oregon amendments before use in a drawing set. Also remember: if your load case isn't a plain floor (a deck at 60 psf, for instance), you must change the Dead/Live load fields above — they do not update automatically from context.

Standard glulam section properties

Sx and I by width and depth, generated on the fly. Covers both the Southern Pine series (5-1/2", 7-1/2", 9-1/2" — matches dimension lumber width) and the Western/DF series (3-1/8", 5-1/8", 6-3/4", 8-3/4" — does not match dimension lumber).

Site design data (by ZIP)

Rough regional planning values for Oregon, Washington, and Idaho sites, to get you in the ballpark before an EOR pulls exact site-specific hazard data.

Values are coarse 3-digit-ZIP regional estimates, not a site-specific hazard report. Ground snow load in the Cascades/Rockies foothills and the eastern Idaho/Yellowstone corridor is strongly elevation- and fault-proximity-dependent — always confirm snow against the state/county-adopted snow load map (SEAO for Oregon; local jurisdiction maps for WA and ID) and confirm wind/seismic against the ASCE 7 Hazard Tool (asce7hazardtool.online) before finalizing a design. Coverage: Oregon (970–979), Washington (980–986, 988–994), and Idaho (832–838) 3-digit ZIP prefixes. Elevations are regional-default (largest city/town in that prefix) — always enter the actual site elevation above when you know it, since it drives the snow load estimate directly.

Rebar shape designer

Pick a typical bar shape, set the bar size and leg dimensions, and export it as a masking-region outline to drop straight into a Revit drafting view. No fill, Medium Lines border, no callouts — matches how you draw these by hand. The preview IS the check: if a shape looks wrong here, it'll be wrong in Revit too, so flag it before using it on a real set.

Bend geometry follows ACI 318 Ch. 25 minimum bend diameters (6db for #3–#8, 8db for #9–#11, 4db for stirrup/tie bends #3–#5) and standard hook extensions — a reasonable field default, not a substitute for checking against the CRSI Manual of Standard Practice or the project's own bar list requirements before fabrication.

Footing sizing (soil bearing)

Square spread footing, sized so the point load spreads to a bearing pressure at or under the soil's allowable value. Preliminary check only.

This sizes the footing for vertical bearing ONLY — it does not check frost depth/embedment, uplift, lateral/seismic loads, eccentricity, overturning, or footing thickness/reinforcing for punching shear or one-way shear. The "allowable soil bearing pressure" options above are common presumptive/default values used when no geotechnical report exists (per typical IRC Table R401.4.1-style defaults) — an actual soils report for the site always governs over these. Confirm frost depth and minimum footing requirements against the locally adopted code (La Grande / Union County, OR typically requires footings below the frost line and a minimum size regardless of what this calculation returns) before use in a drawing set.

Tutorial — sizing a simple deck

A worked example walking Glulam Sizing, Joist Spans, Section Properties, and Footing Sizing together on one real deck, so you can confirm the tool's numbers match a hand check.

This tab is the tutorial itself — it's not going anywhere. There's a separate Footing Sizing tab now too (soil bearing / square footing only). There is still no automatic hookup between the Glulam tab's beam reactions and the Footing tab's load input — you carry that number over by hand, shown below.

The example project

A simple ground-level deck, 12 ft wide (along the house) by 10 ft deep: a ledger bolted to the house on one side, a beam on 3 posts at the outer edge (2 end posts + 1 mid post, so the beam is really two 6-ft bays, not one 12-ft span), and joists spanning between the ledger and the beam.

Plan view — ledger at top, beam on 3 posts at bottom, joists spanning between them. The beam only picks up half the joist span (the ledger/house carries the other half), so its tributary width is about 5 ft, not the full 10 ft.

1 · Glulam Sizing — the beam (a mid-post changes the answer a lot)

Enter: preset Deck (DL 10 / LL 60) · width 5-1/2" · Bay span(s): "6,6" (this is the field to watch — NOT "12", since the mid post breaks the beam into two 6-ft spans) · tributary 5 ft · Fb 2400 · E 1.8 · L/360.

w = (10+60) × 5 = 350 plf per bay  ·  each 6-ft bay: M = 350 × 6²/8 = 1,575 ft-lb  ·  Sx req = 1,575×12/2400 = 7.9 in³  ·  I req = 28.4 in⁴

Tool's answer for "6,6": 5-1/2" x 6" — a much smaller beam than the 5-1/2" x 9" a (wrong) single 12-ft span would call for. Treating the mid post as if it weren't there is the single easiest way to over-order material on a deck this size — or, read backwards, entering "6,6" instead of "12" is the check that catches it.

Each bay is checked as its own simple span (the tool's multi-span input takes the worst bay) — that's conservative versus true continuous-beam behavior, not unconservative. Also: the L/360 deflection check uses combined dead+live load, not live load alone, which is slightly conservative in the same safe direction.

2 · Joist Spans — the joists

Set: Grade No. 1 · preset Deck (DL 10 / LL 60) · deflection L/360. For a 10-ft joist span, No. 1 2x8 @ 16" o.c. now shows about 11'-5" allowable under the deck's 60 psf live load — still enough for our 10-ft span, but noticeably less than the roughly 11'-9" you'd see left over on the residential-floor (40 psf) preset. Switch the preset back to Residential Floor and watch the same row grow — that's the whole point of these being inputs now instead of a fixed table.

These spans come from standard NDS-style Fb/E values with a repetitive-member factor, checking bending and live-load deflection only (no shear, no bearing) — they'll be close to, but won't exactly reproduce, a specific published AWC/IRC table. Still confirm against the adopted code table before it goes on a drawing set.

3 · Section Properties — the cross-check

No inputs here — just Sx and I generated from geometry, so you can verify what Glulam Sizing handed you:

Sx = b·d²/6 = 5.5×6²/6 = 33.0 in³  ·  I = b·d³/12 = 5.5×6³/12 = 99.0 in⁴

Filter Width to 5-1/2" and find the 6" row — it should read Sx 33.0, I 99, matching the Glulam tool's "provided" numbers for the "6,6" case exactly. If those two tabs ever disagree, that's a real bug worth reporting.

4 · Footing Sizing — the posts

Carry the beam's post reactions over by hand (this tool doesn't do it for you): with w = 350 plf and 6-ft bays on each side of the mid post, the end posts each pick up roughly 350×6/2 = 1,050 lb, and the mid post picks up both adjacent half-bays: 350×6/2 + 350×6/2 = 2,100 lb.

Enter: load 2,100 lb (the mid post, worst case) · soil bearing 1,500 psf (presumptive default) · minimum footing 18".

Required area = 2,100 / 1,500 = 1.4 ft² → a bare-minimum side of about 14.2". The 18" minimum you entered governs instead, so the tool suggests an 18" x 18" footing — actual bearing pressure at that size works out to well under the 1,500 psf allowable. That's normal for small deck-post loads: code minimums, not bearing capacity, usually control the footing size.

Always confirm frost depth and the locally adopted minimum footing size/embedment for La Grande / Union County — this calculation only checks bearing pressure, nothing else.

Using this as your own check, going forward

  1. Sketch the framing first and count the actual supports — a mid post means two bays, not one span. This is the mistake that costs the most material if missed.
  2. Work out w, M, and Sx required by hand for your actual span/tributary/load before opening the tool.
  3. Confirm the tool's "required" lines match your hand calc almost exactly.
  4. Cross-check the "provided" Sx/I against Section Properties for that width/depth.
  5. Hand-carry the beam's post reactions into the Footing tab — there's no automatic link between the two tabs.
  6. Still run anything going on a drawing set past a stamped calc or the EOR — this tool is a preliminary field check, not a substitute.
